# 注册及登录

DNfer 是一个群内共用的攻坚排表工具，需要先有一个账号才能使用。本页介绍如何注册、登录，以及注册码是怎么回事。

## 一、注册

首次使用请点击登录页的「凭注册码注册」。

注册需要以下信息：

| 字段 | 说明 |
|---|---|
| 账号 | 登录用，自己起一个（建议与游戏/群内称呼区分，避免撞名） |
| 密码 | 至少 6 位 |
| 群昵称 | 你在群里的称呼（中文 / 字母 / 数字），**排表时展示给全群的名字**，务必与游戏内一致 |
| 注册码 | 管理员生成的邀请码，向群主/管理员索取 |

> 📷 **配图占位**：`images/注册及登录/注册页.png`
> 说明：注册表单，从上到下为 账号 / 密码 / 群昵称 / 注册码 四个输入框。

### 注册码是什么

注册码由管理员在「管理后台 → 邀请码管理」生成，作用是限制谁能加入本系统。它有三种形态：

- **一次性**：一个码只能注册一个人，用后即废
- **多用户**：同一个码可以多人反复使用
- **有效期**：可设置 N 天后过期，过期后无法再用

所以注册失败时，先确认手里的注册码是否被用过 / 是否过期。

> 📷 **配图占位**：`images/注册及登录/注册码失效提示.png`
> 说明：注册时输入了无效注册码的报错提示。

### 机器人自助注册（可选）

如果群机器人接入了本系统，群友也可以直接在群里用 QQ 号注册，无需注册码——机器人会自动帮你建好账号，账号、密码、昵称都是你的 QQ 号。具体玩法见机器人相关文档。

## 二、登录

使用「账号 + 密码」登录。登录后会停留在攻坚列表页。

> 📷 **配图占位**：`images/注册及登录/登录页.png`
> 说明：登录表单，账号 + 密码两个输入框。

## 三、常见问题

- **忘了密码怎么办？** 找管理员帮忙（当前没有自助找回密码功能）。
- **改不了群昵称？** 群昵称可以在「个人信息」里修改，见《2-个人信息》。
- **账号被禁止登录了？** 可能是被管理员封禁，联系管理员核实。

## 下一步

注册并登录后，建议先录入自己的游戏角色（《2-个人信息》），然后就能参加攻坚排表了（《3-参团报名》）。
