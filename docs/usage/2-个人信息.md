# 个人信息

本页介绍如何维护你的个人资料与游戏角色。角色数据是排表的基础——**报名字前请先把自己的角色录好**。

## 一、个人资料

登录后点击右上角的头像（或昵称），会弹出「个人信息」面板，在这里可以：

- 修改**群昵称**（排表时展示给全群的名字）
- 上传 / 更换**头像**

> 📷 **配图占位**：`images/个人信息/资料面板.png`
> 说明：右上角头像弹出的个人信息面板，含昵称输入框与头像上传。

## 二、我的角色

顶部导航点「我的角色」，进入角色列表页。这里展示你名下的所有游戏角色。

### 添加角色

点击「添加角色」，填写：

| 字段 | 说明 |
|---|---|
| 角色名 | 游戏内角色名称 |
| 职业 | 从职业树中选择（16 大类 × 子职业）；部分职业分男女双版，选对应版本即可 |
| 名望 | 角色名望值，用于排序与参考 |

> 📷 **配图占位**：`images/个人信息/添加角色表单.png`
> 说明：添加角色弹窗，含 角色名 / 职业选择 / 名望 三个部分。

### 输出 / 辅助

系统会根据所选职业**自动判断**该角色是「输出」还是「辅助」：

- **辅助职业**（男女圣骑士、协战师、小魔女、缪斯）→ 归为辅助
- 其余职业 → 归为输出

在排表时，输出角色用**伤害**说话、辅助角色用**增益**说话，所以添加角色时请补上对应数据：

| 角色类型 | 需要填写 |
|---|---|
| 输出 | 模拟伤害、秒伤 |
| 辅助 | 增益量 |

> 📷 **配图占位**：`images/个人信息/输出辅助字段.png`
> 说明：添加/编辑角色时，输出角色显示 模拟伤害、秒伤 字段；辅助角色显示 增益量 字段。

### 角色列表与排序

- 角色卡片展示：角色名、职业图标与名称、类型（输出/辅助）、战力数值、名望
- 列表**默认按类型**（输出在前、辅助在后）排列，可在右上角切换为**按名望降序**

> 📷 **配图占位**：`images/个人信息/角色列表.png`
> 说明：我的角色列表页，输出/辅助分组，卡片含职业图标与战力。

### 编辑 / 删除

每个角色卡片提供编辑与删除操作。删除角色前请确认：该角色若已占用在攻坚中，可能影响排表（管理员会在后台处理）。

> 📷 **配图占位**：`images/个人信息/角色操作按钮.png`
> 说明：角色卡片上的 编辑 / 删除 按钮位置。

## 常见问题

- **职业选错了怎么办？** 编辑该角色重新选择即可。
- **男女双版职业**：标题带（男）/（女）的职业为男女双版，按实际角色选择；单性别职业则无标注。
- **为什么没有「输出/辅助」手动开关？** 类型由职业自动推导，无需也不可手动改。
