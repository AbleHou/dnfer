# 辅助职业「太阳增益」字段 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为辅助职业新增「太阳增益」（`sun_buff`）数值字段，全链路接入（表单录入、角色卡片/我的角色/报名战力列/占位格展示、管理查询表与排序、机器人接口），完全镜像既有 `buff_amount` 模式。

**Architecture:** 后端 `Character` 模型加 `sun_buff: Integer | None` 列 + 幂等迁移；`CharacterIn/Out/SlotOut/BotCharacterIn` 加字段；共享 `character_out`/`apply_character_payload`/`_slot_out`/`_apply_partial` 透传；admin `_SORT_COLS` 加 `sun_buff`。前端 `types.ts` `Character`/`Slot` 加必填 `sun_buff`（牵连 13 个 spec fixture），`CharacterForm` 辅助分支加输入框，5 处展示点（CharacterCard/MyCharactersView/SlotCell/SignupModal powerText/AdminUsersView 表+排序）改为辅助显示 `增益 X · 太阳 Y` 或 `增益/太阳`。

**Tech Stack:** FastAPI + SQLAlchemy 2 + SQLite（后端测试 `cd backend && .venv/bin/python -m pytest <file> -v`）；Vue 3 (`<script setup lang="ts">`) + Vitest（`cd frontend && npx vitest run <file>`）；类型/构建 `cd frontend && npm run build`（= vue-tsc -b && vite build，vitest 不做类型检查）。

**Spec:** `docs/superpowers/specs/2026-09-29-sun-buff-design.md`

**前置环境约定（务必遵守）：**
- 提交直接到 main（仓库既定约定，不做 worktree）；提交信息用 `[feat]/[fix]/[docs]/[test]` + 中文描述 + `Co-Authored-By: Claude Opus 4.6 <noreply@anthropic.com>` 尾注。
- 后端测试 venv 在 `backend/.venv`；所有后端 pytest 前 `cd backend`。
- 前端 vitest（esbuild）不做类型检查，`types.ts` 加必填字段后必须先补全所有 fixture 再跑 `npm run build` 验证。
- 后端不做按职业的强制校验（与 `buff_amount` 一致）：纯前端按职业显隐输入框，后端只存透传。
- `sun_buff` 是纯展示字段，不参与任何计算（`lib/damage.ts` 小队统计只聚合输出职业，不动）。

    from . import models  # noqa: F401  确保模型注册
    from .db import Base

        cols = {row[1] for row in conn.execute(text("PRAGMA table_info(characters)")).all()}
