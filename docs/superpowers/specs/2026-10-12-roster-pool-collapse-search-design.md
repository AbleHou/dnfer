# 编队角色池增强（折叠 + 全部展开/收起 + 用户名搜索）— 设计规格

日期：2026-10-12
状态：已确认
需求来源：用户口述——编队页左侧角色池较长时，想按用户收起角色以减少滚动；加一个仅前端搜索框便于快速定位；并配「全部展开/收起」按钮。已确认的决策：**搜索按用户名（昵称）匹配、角色名不参与、搜索不改变折叠态**（用户澄清）；**默认全部展开**。

## 1. 目标

让编队页左侧角色池（`RosterPool.vue`）更易浏览与定位：

- 点用户名头折叠/展开该用户组角色；
- 工具栏提供「全部展开」「全部收起」一键按钮；
- 前端本地搜索框按**昵称**过滤用户组（角色名不参与，搜索不改折叠态）。

**范围**：仅 `RosterPool.vue` 组件 + `RosterPool.spec.ts` 测试；纯前端，不改数据/后端，不动 `RosterView.vue` 与其它组件。

## 2. 交互与状态

### 2.1 组件内部状态（内存态，离开页面重置，不做 localStorage 持久化）

- `collapsed: Set<number>` — 已收起用户组（user.id 集合），初始为空（全展开）。
- `query: string` — 搜索词，初始 `''`。

### 2.2 用户组折叠

- 点 `.pool-user-head`（用户名头）切换该组的展开/收起（toggle `collapsed` 中对应 user.id）。
- **默认全部展开**（与现状一致，保证现有测试与体验不变）。
- 收起时该组角色**不渲染**（`v-if`），仅渲染用户名头；头部加折叠指示符 `▸`（收起）/`▾`（展开）+ 昵称，示意可点。
- 头部点击不触发角色 pick（本身头与角色卡是不同元素）。

### 2.3 全部展开 / 全部收起

- 池顶部工具栏两个按钮：「全部展开」「全部收起」。
- 全部展开 → `collapsed` 清空；全部收起 → `collapsed` 置为所有用户组 user.id。

### 2.4 用户名搜索框

- 池顶部工具栏输入框（`data-act="pool-search"`）。
- 过滤规则：`query.trim().toLowerCase()` 为空 → 显示全部用户组；否则仅显示 `user.nickname.toLowerCase().includes(q)` 的用户组，无匹配整组隐藏。
- **角色名不参与匹配**；**不改变 `collapsed`**（整组显示/隐藏与折叠互不干扰——已澄清）。

### 2.5 过滤与折叠的叠加

- 搜索过滤先于折叠：先按昵称选出可见组，再按各组的展开态渲染角色。
- 搜索中某组被收起：显示该组用户名头（匹配昵称），角色不渲染，点头可展开——折叠态独立于搜索。

## 3. 实现要点

- `RosterPool.vue` 现有 `groups` computed（按用户分组、组内战力排序、过滤 0 角色）保留；新增 `visibleGroups` computed（叠加昵称过滤）。
- 渲染：`v-for="g in visibleGroups"`；`.pool-user-head` 加 `@click` toggle + 指示符；组内角色 `v-if="!collapsed.has(g.user.id)"`。
- 工具栏置于 `.roster-pool` 顶部：搜索框 + 「全部展开」「全部收起」按钮。
- 样式沿用现有 inline/scoped 风格（`--dnf-border`/`--dnf-accent` 等带 fallback）。

## 4. 测试（RosterPool.spec.ts 新增）

新增用例（现有 10 例保持通过）：

- 点用户名头收起：该组角色不再渲染（`findAll('.pool-char')` 减少 / 对应角色 `exists()` false），再点恢复。
- 收起指示符：收起后头部含 `▸`，展开含 `▾`。
- 「全部收起」后所有组角色不渲染；「全部展开」后全部渲染。
- 搜索按昵称：含关键词的组保留、不含的整组隐藏（`data-act` 命中）。
- 搜索不改变折叠态：搜索中某组原本收起仍收起、展开仍展开。
- 空搜索/清空后显示全部。

测试注意：折叠用 `v-if`（收起后角色从 DOM 移除），搜索过滤也整组移除；断言用 `exists()`/`findAll` 计数而非 `text()`（隐藏元素文本仍会被 `text()` 收集，不可靠）。

## 5. 风险

- 低：单组件 + 单测试文件，纯前端状态，无数据流/后端改动。
- 现有 `RosterView.spec.ts` 的池交互断言（`pool-char-*` 点击）依赖默认全展开——已按「默认全展开」保证不破坏。
- 搜索框/工具栏可能使池顶部变高——角色池 `max-height:70vh` 内部滚动不变，工具栏随池滚动，无布局风险。

## 6. 范围外

- 不做 localStorage 持久化折叠/搜索态。
- 不改用户分组/排序逻辑、推荐/划水/拿起逻辑。
- 搜索仅匹配昵称，不支持职业/角色名/多关键词。
